# Quran division metadata

`divisions.json` contains only navigation boundaries. It does not contain or modify Quran text.

- Source: Tanzil Project, [Quran Metadata](https://tanzil.net/docs/Quran_Metadata), metadata XML version 1.0: <https://tanzil.net/res/text/metadata/quran-data.xml>.
- Review copy of the same XML structure and records: <https://github.com/myquranapp/quran-data/blob/master/quran-data.xml>.
- Edition: Tanzil's Quran structural metadata, with page navigation using this app's existing 604-page Madani Mushaf layout.
- License and attribution: Creative Commons Attribution 3.0 (CC BY 3.0); attribute Quran metadata to the Tanzil Project (tanzil.net). See [Tanzil Text License](https://tanzil.net/docs/Text_License).
- Verification: the 240 quarter starts are stored in source order from the XML `quarter` records. The 60 Hizb starts are every fourth quarter boundary. Juz and page boundaries continue to come from the app's existing separate `juz.json` and `layout.json`; neither is recalculated here. `npm run test:navigation` checks the division counts, valid coordinates, ordering, each entry's resolution, and all 604 existing page starts.

The quarter list is not generated by splitting Surahs, Juz, or Ayah counts evenly. The layout and verified Quran text files remain unchanged.
